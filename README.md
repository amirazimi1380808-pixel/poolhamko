# پول‌هام 💸 (Poolham) - نسخهٔ جدید (V3)

یک وب‌اپلیکیشن (PWA) پیشرفته، آفلاین و کاملاً راست‌چین برای مدیریت شخصی مالی، ردیابی هزینه‌ها، بودجه‌بندی و اهداف پس‌انداز. 

این نسخه، بازنویسی کامل و ارتقایافتهٔ نسخه‌های قبلی است که در یک فایل `index.html` یکپارچه (به همراه فایل‌های کش و PWA) خلاصه شده است و نیازی به هیچ سرور یا دیتابیسی ندارد (تمام داده‌ها روی دستگاه شما رمزنگاری و ذخیره می‌شوند).

---

## ✨ امکانات جدید در این نسخه

- **طراحی و UI/UX جدید و منعطف:** 
  - پشتیبانی از استایل‌های بصری متنوع: **کلاسیک، Liquid Glass (شیشه‌ای)، چوبی 🪵، کاغذی 📄 و نیمه‌شب 🌌**.
  - ۶ تم رنگی اختصاصی (بنفش، سبز زمردی، آبی، رزگلد، طلایی کهربایی و آکوامارین 🌊).
  - سازگاری کامل با حالت تاریک (Dark Mode).
- **انتقال بین حساب‌ها:** امکان جابه‌جایی پول بین حساب‌های مختلف (مثلاً از کارت بانک ملت به پول نقد) بدون ثبت به‌عنوان درآمد/هزینهٔ اضافی.
- **قلک و اهداف پس‌انداز هوشمند:** قلک‌ها حالا به تراکنش‌های واقعی و حساب‌های شما متصل هستند. واریز به قلک مستقیماً از حساب شما کسر می‌شود.
- **امنیت بالا:** امکان تنظیم پین‌کد (PIN) برای ورود به اپلیکیشن. داده‌ها با امنیت بالا در `localStorage` مرورگر ذخیره می‌شوند.
- **بکاپ و بازیابی کامل:** بکاپ‌گیری JSON که حالا شامل اهداف پس‌انداز و دفترچهٔ شبا نیز می‌شود.
- **عملکرد کاملاً آفلاین (PWA):** با یک بار باز کردن، می‌توانید اپلیکیشن را روی صفحه اصلی گوشی (Add to Home Screen) نصب کنید و بدون اینترنت از آن استفاده کنید.
- **راست‌چین و فارسی استاندارد:** استفاده از فونت استاندارد «وزیرمتن» (Vazirmatn) و نمایش صحیح اعداد فارسی در تمامی بخش‌ها و نمودارها.

## 🚀 راهنمای نصب و استفاده

این اپلیکیشن **نیازی به نصب Node.js، سرور یا بیلد کردن ندارد.**

### روش اول: استفادهٔ مستقیم (سریع‌ترین راه)
۱. فایل `index.html` را در هر مرورگری (کروم، سافاری، فایرفاکس) باز کنید.
۲. برنامه بلافاصله اجرا می‌شود!

### روش دوم: نصب روی گوشی (PWA)
اگر فایل‌ها را روی یک هاست (مثل GitHub Pages، Vercel یا هر هاست ساده‌ای) آپلود کنید:
۱. لینک سایت خود را در مرورگر گوشی (Safari در آیفون یا Chrome در اندروید) باز کنید.
۲. در منوی مرورگر، گزینهٔ **Add to Home Screen** (افزودن به صفحه اصلی) را انتخاب کنید.
۳. حالا اپلیکیشن مثل یک برنامهٔ بومی روی گوشی شما نصب شده است و بدون اینترنت هم کار می‌کند.

### روش سوم: اجرا با سرور محلی (برای توسعه‌دهندگان)
اگر می‌خواهید تغییراتی در کد بدهید و کش مرورگر اذیتتان نکند:
```bash
# با استفاده از پایتون
python -m http.server 8000

# یا با استفاده از Node.js
npx serve .
```
سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

## 📂 ساختار فایل‌ها

- `index.html`: هستهٔ اصلی برنامه (شامل HTML, CSS و کدهای جاوااسکریپت).
- `manifest.webmanifest` و `sw.js`: فایل‌های لازم برای نصب اپلیکیشن به صورت آفلاین (PWA).
- `vendor/`: کتابخانه‌های خارجی (Tailwind CSS, Chart.js, Lucide Icons) به صورت آفلاین تا بدون اینترنت کار کنند.
- `vendor/fonts/`: فونت وزیرمتن.
- `theme-gallery.html`: گالری پیش‌نمایش تم‌ها و استایل‌های برنامه.
- `icons/`: آیکون‌های برنامه برای نصب در سایزهای مختلف.

## 🛠 رفع مسئولیت
این برنامه تمام اطلاعات را **فقط در مرورگر شما** ذخیره می‌کند و هیچ داده‌ای به هیچ سروری ارسال نمی‌شود. برای جلوگیری از پاک شدن اتفاقی داده‌ها (مثلاً با پاک کردن تاریخچه مرورگر)، مرتباً از بخش تنظیمات **بکاپ بگیرید**.
